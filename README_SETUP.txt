CAPVAULT V2 SETUP
1. Maak een Firebase project.
2. Authentication > Sign-in method > Google inschakelen.
3. Firestore Database maken.
4. Storage maken.
5. Registreer een Web App en zet de Firebase config in script.js.
6. Voeg je GitHub Pages domein toe bij Authentication > Settings > Authorized domains.
7. Publiceer de bestanden op GitHub Pages.
8. Publiceer firestore.rules en storage.rules in Firebase.
Supporttickets en aankoopbewijzen zijn niet publiek leesbaar. Maak voor jezelf een beveiligde admin-workflow om tickets te behandelen.
